## 二、建议的后续优化（可选）

1. **子技能是否被自动调用**主技能里写的是「使用 [HTML结构生成技能]」等链接，Agent 不一定会自动打开子 skill。若希望更强约束，可在主 SKILL.md 的「快速开始」里直接写清：先读 `html-structure/SKILL.md` 再生成 HTML，或把关键片段（如模板、@import 规则）精简摘进主 skill，减少跳转。
2. **与 create-skill 的「简洁」原则**各 SKILL 已控制在 500 行内。若仍觉冗长，可把长代码块移到 `reference/` 或 `examples.md`，主 skill 只保留步骤和 1～2 个最短示例。
3. **项目中的拼写**`src/common/common.css` 里有 `background-pisition`（应为 position），属既有 typo。Skill 中未写入该错误名称，避免固化错误；若将来改 common.css，可一并修正。
4. **平台页数据文件**
   平台页（尤其移动端）使用 `platform-m/xxxData.js` + `template.js` 渲染，可在主 skill 或 reference 中加一句「平台页若需数据驱动，参考 `src/js/platform-m/` 下的 Data 与 template」，方便生成一致结构。
